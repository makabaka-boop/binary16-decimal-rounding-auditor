# halfconv — 十进制 → IEEE binary16 精确转换器

仪器把十进制测值压成半精度浮点时，常见的“先转宿主 `double` 再强制转换”路线有两类隐患：

1. **二次舍入**：十进制 → double 已经舍入过一次，再舍入到 binary16 时，恰好落在居中点附近的值会被带偏。例如 `1.00048828125000000000000000001`（居中点 `1+2^-11` 上方 `10^-29` 处）先转 double 会塌缩到居中点上，再按“居中取偶”错误地舍向 `0x3c00`；正确结果是 `0x3c01`。
2. **符号零丢失**：绝对值小于 `2^-25` 的负测值应得到 `-0`（`0x8000`），宿主路线容易悄悄变成 `+0`。

本工具**完全不借助宿主浮点**：解析、比较、舍入全部用 `math/big` 的整数与有理数完成，每个舍入决定都是精确的。

## 构建与测试

```sh
go build ./...
go test ./...
```

测试包含：

- **全量编码往返**：全部 63488 个有限 binary16 位型（含 ±0、全部次正规），逐一精确解码成十进制字符串后再转换，必须回到原位型、分类一致、误差为零；
- 次正规边界（`2^-24`、`2^-14`、次正规/正规交界居中点 `2047·2^-25` 等）；
- 正负零与下溢保号（`-1e-10` → `0x8000`）；
- 居中点取偶（`1+2^-11` → `0x3c00`，`2049·2^-11` 两侧 1/4 网格偏移）；
- 二次舍入陷阱（见上，宿主 double 路线会算错的值）；
- 溢出（`65504` 保持有限、`65520` 居中点 → `+Inf`、`65519.9921875` → `0x7bff`）；
- 非法输入拒绝与批量上限。

## 输入契约

每批 1～1000 个十进制字符串，JSON 信封：

```json
{"values": ["0.1", "-1e-10", "65520"]}
```

每个值的文法（不允许空白、不允许 `NaN`/`Infinity`）：

```
[+-]? ( [0-9]+ ('.' [0-9]*)? | '.' [0-9]+ ) ( [eE] [+-]? [0-9]{1,2} )?
```

约束：

- 有效数字（剥去前导零与末尾零后）至多 **30** 位；
- 首位有效数字的十进制指数（科学计数法指数）在 **[-50, 50]** 内；
- 显式指数本身也限 [-50, 50]（两位以内）。

不满足约束的值按**条目**拒绝（`ok:false`），不影响同批其他值；信封非法或批量越界（0 或 >1000）整体报错、退出码 1。

## 输出协议

```json
{
  "count": 2,
  "results": [
    {
      "input": "0.1",
      "ok": true,
      "error": null,
      "hex": "2e66",
      "bits": "0b0010111001100110",
      "class": "normal",
      "rounded": "0.0999755859375",
      "delta": {"num": "-1", "den": "40960"}
    },
    {
      "input": "65520",
      "ok": true,
      "error": null,
      "hex": "7c00",
      "bits": "0b0111110000000000",
      "class": "infinity",
      "rounded": "Infinity",
      "delta": null
    }
  ]
}
```

- `hex`：四位小写十六进制位型；
- `class`：`zero` / `subnormal` / `normal` / `infinity`；
- `rounded`：舍入后有限值的精确十进制（`-0` 保留符号）；
- `delta`：舍入值 − 原值的**最简分数**（`big.Rat` 自动约分）；无穷结果为 `null`。

## 算法要点

1. 十进制串解析为 `符号 × 系数 × 10^指数`（`big.Int`），再得精确有理数；
2. 用整数位长估计并精确校正得到 `k = ⌊log2|x|⌋`；
3. `k ≤ -15`：按次正规网格 `2^-24` 缩放，`roundEven`（截断商 + 余数两倍与分母比较，居中看奇偶）；
4. `-14 ≤ k ≤ 15`：按网格 `2^(k-10)` 缩放舍入；`m=2048` 时进位到下一 binade，`k=15` 时进位即无穷（`65520` 居中点取偶到无穷）；
5. `k ≥ 16`：直接 ±Inf；
6. 零幅值与下溢到零的值保留输入符号（`-0`）。

`roundEven` 全程只比较 `big.Int`，没有任何宿主浮点参与舍入决定。

## 命令行用法

```sh
halfconv [file.json]          # 无参数时读标准输入
echo '{"values":["0.1"]}' | halfconv
```

## Docker Compose

`half` 服务负责批量运行，默认转换 `samples/batch.json`：

```sh
docker compose run --rm half                                  # 内置样例
docker compose run --rm -v "$PWD/mybatch.json:/data/batch.json:ro" half
docker compose run --rm -T half < mybatch.json                # stdin 流式
```

镜像为多阶段构建（`golang:1.23` 编译静态二进制，`distroless` 运行），模块仅用标准库，构建无需外网。
